# Kết quả cục bộ

WAV để nghe được tạo trực tiếp tại đây; log, JSON, PCM và raw nằm trong
`du_lieu_kiem_thu/`. Các bản thu giọng nói và kết quả chạy không đưa lên Git.

Nhánh `debug` hỗ trợ lấy cặp PCM đầu vào/đầu ra bằng công cụ
`firmware_esp32s3/kiem_thu_esp32s3/host/filter_listen_test.py`.
Nhánh `main` chạy mic → lọc → loa, không lưu cặp kiểm thử.
